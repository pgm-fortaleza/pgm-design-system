Portal PGM

Cores, letras, cantos e espaçamentos que as telas novas dos sistemas da PGM usam. Os três produtos seguem os mesmos papéis do Material Design 3: um botão principal é sempre "Principal", só a cor muda de produto para produto.

Cores

Cada cartão mostra uma cor de fundo com o texto que deve ir sobre ela, o nome do token e o contraste entre os dois. Contraste a partir de 4,5:1 atende o nível AA de acessibilidade para texto comum.

Comparar produtos

Os mesmos papéis lado a lado nos três produtos, no modo de cor selecionado.

Tipografia

Montserrat em todos os produtos. Tamanho e altura de linha de cada estilo.

Cantos arredondados

Para deixar os botões menos arredondados em todos os sistemas, muda-se o token usado por eles aqui, e a nova versão chega a cada sistema como uma atualização.

Espaçamento e elevação

Espaços em múltiplos de 4 px e cinco níveis de sombra.

Como usar

Para quem desenvolve. Cada sistema instala a biblioteca por uma versão fixa.

Instalar a versão no projeto:

npm i github:pgm-fortaleza/pgm-design-system#v__VERSION__

Carregar os tokens de um produto:

import "@pgm/design-system/tokens/css/base.css";
import "@pgm/design-system/tokens/css/portal.css";
Gerado a partir de devpgm/pgm-design-system v__VERSION__. Temas dos Ágilis provisórios até a definição do design.
